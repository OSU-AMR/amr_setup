# AMR Setup

This is everything needed to setup an AMR. This is definently not based on riptide_setup in the slightest. (thanks Cole)

## INSTALL

Clone this repo next to the src directory. Then follow the instructions in install.sh to install this package as a pip package.

## Verbs

These are command that colcon can perform. The man should work decently well to describe commands and flags.

## How to Setup New Robot

The .rtf file gives good documentation on how to setup a new robot. Be sure to read through errors given by setup AMR. Unforueatly, some "errors" are benign. It is advisable to follow this process to the T to avoid any networking issues.

## New Laptop Setup

There is no formal process but one should be created. Definently reserve an IP in the router and install all packages in setup.bash on the operator laptop (in addition to installing this package).
